Skrypty, którymi z oryginalnych rysunków (folder `art/`, tylko na komputerze, bez gita) powstały obrazki w `img/avatar/`.
Potrzebują Pythona z Pillow, numpy i scipy. Ścieżki w skryptach są na stałe do folderu Pumpelek.

Kolejność: cut_hair.py (cięcie arkuszy fryzur) → fit.py (dopasowanie fryzur do głowy) → outfits.py i export_outfits.py (stroje pod głową)
→ place_acc.py (dodatki) → export_web.py (kolory włosów, odcienie skóry, WebP i lista położeń).
